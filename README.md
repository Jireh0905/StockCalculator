# Jireh

주식 손익 계산기를 시작으로, 여러 주식 계산 도구를 한곳에서 쓰는 웹앱이에요.

배포 주소: https://jireh0905.github.io/stock/

- 첫 화면(홈)에서 기능을 고르고, 왼쪽 메뉴로 언제든 다른 기능으로 바꿀 수 있어요.
- 기능마다 고유 주소가 있어요. 예) `…/stock/#/split` → 분할 매매 계산기 (예전 주소 `#/average`도 자동으로 옮겨줘요)
- 계산기 맨 위의 **[국내 주식 | 해외 주식]** 버튼은 모든 계산기가 함께 따라가요. 한 곳에서 해외로 바꾸면
  다른 계산기도 해외(달러, 해외 수수료·양도소득세)로 열려요. 국내 값과 해외 값은 따로 기억해서 바꿔도 지워지지 않아요.
- 입력값과 계산 기록은 **창(탭)이 열려 있는 동안만** 남아요. 다른 기능으로 이동하거나 새로고침해도 그대로이고,
  탭을 닫고 다시 접속하면 처음 상태로 시작해요. 메뉴 아래 "지금 모두 초기화"로 바로 지울 수도 있어요.
- 같은 메뉴 그룹(예: 계산기)의 기능끼리는 계산 기록을 함께 봐요. 기록 창 위쪽 칩으로 "이 기능만" 볼 수도 있고,
  다른 계산기의 기록을 누르면 그 계산기로 이동해서 값을 불러와요.
- **분할 매매 계산기** (예전 물타기 계산기)
  - **분할 매수:** 나눠서 더 사면 평균 단가가 얼마가 되는지 보여줘요.
  - **분할 매도:** "매도가 + 수량"을 단계로 늘리고 줄여요. 단계별 받는 돈·순이익, 평균 매도가,
    그리고 **남은 주식의 실질 단가**(넣은 돈 − 받은 돈 ÷ 남은 수량)를 보여줘요. 받은 돈이 넣은 돈보다 많으면 "원금 회수 완료".
    해외는 환율을 넣으면 양도소득세(기본 공제 250만 원 뒤 22%)를 원화로 계산해요.
- 계산 결과를 다른 계산기로 바로 넘길 수 있어요. 분할 매수 결과의 "이 평단으로 이어서 계산"에서
  - **목표가 계산 →** 새 평단이 목표가 계산기의 매수가로 들어가요 (목표 수익률·수수료는 원래 값 유지).
  - **손익 계산 →** 새 평단(소수 둘째 자리까지)과 총 보유 수량이 손익 계산기로 들어가고,
    커서가 매도가 칸으로 가요. 매도가만 바꿔 보며 예상 순손익과 매도로 받을 돈을 볼 수 있어요.
- **배당금 계산기**
  - **내 배당:** 주당 배당금(1회)·배당 주기·보유 수량으로 1회·한 달·1년 세후 배당과 배당 수익률(현재가·내 평단 기준)을 보여줘요.
  - **목표 배당:** "한 달(1년)에 세후 얼마 받으려면?" → 필요한 수량(1주 단위 올림)과 투자금, 가진 돈으로는 얼마가 되는지.
  - 세금: 국내 배당소득세 15.4%, 해외는 현지 원천징수(미국 15%). 해외는 환율을 넣으면 원화로도 보여줘요.
  - 1년 세전 배당이 2,000만 원을 넘으면 금융소득종합과세 경고를 보여줘요.
- **적립식 계산기**
  - **얼마가 될까:** 처음 넣는 돈 + 매달 넣는 돈을 주가 상승률·배당률로 굴리면 기간 뒤 얼마가 되는지.
    연도별 막대그래프(원금 + 수익, 막대를 누르면 그 해 금액)와 연도별 표, 배당 재투자 효과, 72 법칙, 물가 반영.
  - **목표 금액:** 기간 뒤 목표를 만들려면 매달 얼마를 넣어야 하는지 (국내 1,000원, 해외 $1 단위 올림).
  - 해외는 다 팔 때 양도소득세(기본 공제 뒤)와 원화 환산을 보여줘요. 배당 계산기의 "적립식으로 보기 →"로 이어져요.
- **목표가 계산기**는 해외에서 목표가를 두 가지로 보여줘요. 양도세 공제(250만 원) 안이면 세금 없는 목표가,
  공제를 다 썼다면 22%를 떼고도 목표 수익률이 되는 가격이에요.
- **하락 대응 계산기**는 주가가 떨어졌을 때의 계획을 세워요.
  - **물타기 계획:** "매수가 + 목표 평단"을 한 세트로 단계를 늘리고 줄여요. 단계마다 몇 주를 사야 하는지,
    본전 가격이 얼마나 내려가는지, 손절선까지 가면 얼마를 잃는지 보여줘요.
  - **손절 후 재매수:** 손절가에 모두 팔고 재매수가에 다시 사면 확정 손실과 새 본전 가격이 얼마인지 보여줘요.
  - 두 탭을 모두 입력하면 **그대로 보유 / 물타기 / 손절 후 재매수**를 본전 가격·추가로 넣는 돈·보유 수량으로 비교해요.
    (어느 쪽이 낫다고 추천하지는 않고 숫자만 나란히 보여줘요)

## 폴더 구조

```
index.html              모든 화면이 함께 쓰는 틀 (왼쪽 메뉴, 상단 바, 기록 시트)
css/
  style.css             화면 꾸미기 (색상·배치·다크 모드)
js/
  app.js                시작점: 라우터(주소 → 화면), 공통 틀 연결
  features.js           기능 목록 (여기에 추가하면 메뉴·홈에 자동 표시)
  home.js               첫 화면: 기능 카드 + 이번 방문 기록
  shell/                공통 틀의 부품
    drawer.js             왼쪽 메뉴
    history-sheet.js      계산 기록 시트
    record-item.js        기록 한 줄 (시트·홈 공용)
  core/                 모든 기능이 함께 쓰는 도구
    session.js            이번 방문 동안의 저장소 (sessionStorage)
    number-input.js       숫자 입력칸: 자동 쉼표, 값 읽기·채우기
    format.js             숫자 포맷 (쉼표, 원화, 퍼센트)
    market.js             국내/해외: 선택 버튼, 원/$ 금액 표시, 시장별 수수료·세금 기본값
    received.js           다른 기능에서 받은 값 표시 (칸 강조 + 알림)
    icons.js              메뉴·카드 아이콘
    toast.js              하단 알림
  features/             기능 하나 = 폴더 하나
    profit/               손익 계산기 (template·calculator·result-view·index)
    split/                분할 매매 계산기 (분할 매수 · 분할 매도)
    plan/                 하락 대응 계산기 (물타기 계획 · 손절 후 재매수 · 비교)
    dividend/             배당금 계산기 (내 배당 · 목표 배당)
    saving/               적립식 계산기 (얼마가 될까 · 목표 금액, chart.js = SVG 막대그래프)
    target/               목표가 계산기
serve.py                로컬 개발용 웹 서버 (2단계에서 Vite로 대체 예정)
```

화면이 바뀌는 흐름:

```
메뉴·카드 클릭 → 주소가 #/split으로 바뀜 → app.js의 render()
   → features.js에서 'split' 기능을 찾음
   → markets: true인 기능이면 맨 위에 국내/해외 버튼을 그림 (core/market.js)
   → 그 기능의 mount()가 가운데 화면을 그림 (ctx.market으로 지금 시장을 알려줌)

국내/해외 버튼 클릭 → session에 시장 저장 → render()로 같은 기능을 새 시장으로 다시 그림
   (입력값은 { domestic: {...}, global: {...} }로 따로 저장. 기능은 이걸 몰라도 되고 ctx.inputs만 써요)
```

계산 흐름 (기능 하나 안에서):

```
입력칸 ──(number-input.js)──▶ 입력값 ──(calculator.js)──▶ 결과 ──(화면 그리기)──▶ 화면
   │                                                      │
   └── 글자 입력할 때마다 ──┐            기록에 저장 ───┘
                            ▼                  ▼
                     core/session.js  →  sessionStorage
```

## 새 기능 추가하는 법

1. `js/features/<id>/` 폴더를 만들고 `split/`을 본떠 `index.js`(화면+연결)와 `calculator.js`(계산)를 만들어요.
2. `js/features.js`에서 import하고 `FEATURES` 목록에 넣어요. 끝 — 메뉴와 홈 카드에 저절로 나타나요.
3. 국내/해외에 따라 계산이 달라지면 기능에 `markets: true`를 넣고, `ctx.market`과 `core/market.js`의
   `moneyInput()`(입력칸), `price()`·`money()`(금액 글자)를 써요.

## 기능끼리 값 넘기기

보내는 기능은 받는 기능의 저장 모양을 몰라도 돼요. 받는 기능이 `receive()`로 "무엇을 받을지"를 직접 정해요.

```
보내는 쪽 (split/index.js)          ctx.sendTo('target', { buyPrice: 47333 })
        │
        ▼
app.js sendTo()                     1. target.receive(지금 입력값, 받은 값, 시장) → 새 입력값 저장
                                       (국내/해외는 모든 기능이 함께 쓰니까 같은 시장으로 넘어가요)
                                    2. #/target 으로 이동
        │
        ▼
받는 쪽 (target/index.js)            receive(): 매수가만 바꾼 입력값을 돌려줌
                                    mount(): ctx.received가 있으면 매수가 칸 강조 + 알림 (core/received.js)
```

다른 기능도 값을 받게 하려면 그 기능의 `index.js`에 `receive(inputs, payload, market)`만 추가하면 돼요.
`app.js`는 고칠 필요가 없어요. 손익 계산기(`profit/index.js`)도 이렇게 `receive()`만 더해서 연결했어요.

지금 연결된 길:

| 보내는 기능 | 받는 기능 | 넘기는 값 |
|---|---|---|
| 분할 매매 (분할 매수) | 목표가 | 새 평단 (국내 원 단위, 해외 센트까지) |
| 분할 매매 (분할 매수) | 손익 | 새 평단 (소수 둘째 자리) + 총 보유 수량 |
| 분할 매매 (분할 매수) | 배당 (내 배당) | 새 평단 → 내 평단, 총 보유 수량 → 보유 수량 |
| 배당 (내 배당) | 적립식 (얼마가 될까) | 지금 평가 금액 → 처음 넣는 돈, 배당 수익률·배당세, 배당 다시 투자 |
| 하락 대응 (물타기 계획) | 분할 매매 (분할 매수) | 평단·보유 수량 + 단계별 추가 매수 (기존 추가 매수 줄은 이 단계들로 바뀜) |
| 하락 대응 (물타기 계획) | 손익 | 최종 평단 (소수 둘째 자리) + 총 보유 수량 |
| 하락 대응 (손절 후 재매수) | 손익 | 재매수가 + 재매수 수량 |

## 로컬에서 실행하기

JavaScript 모듈(`<script type="module">`)은 보안 규칙 때문에
`index.html`을 **더블클릭해서 열면 동작하지 않아요** (`file://` 주소에서는 모듈을 불러올 수 없음).
아래 방법 중 하나로 간단한 로컬 서버를 띄워서 열어야 해요.

**방법 1. Python** (이 폴더에서 실행)

```bash
py serve.py
```

브라우저에서 http://localhost:8000 접속 (끝내려면 터미널에서 Ctrl+C)

> `py -m http.server`를 그대로 쓰면 Windows에서는 `.js` 파일이 `text/plain` 형식으로 전달돼서
> 모듈이 실행되지 않을 수 있어요. `serve.py`는 이 문제를 바로잡은 버전이에요.

**방법 2. VS Code 확장 "Live Server"**

`index.html`을 연 상태에서 오른쪽 아래 **Go Live** 클릭 → 저장할 때마다 자동 새로고침
