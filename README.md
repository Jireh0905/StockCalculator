# Jireh

주식 손익 계산기를 시작으로, 여러 주식 계산 도구를 한곳에서 쓰는 웹앱이에요.

배포 주소: https://jireh0905.github.io/stock/

- 첫 화면(홈)에서 기능을 고르고, 왼쪽 메뉴로 언제든 다른 기능으로 바꿀 수 있어요.
- 기능마다 고유 주소가 있어요. 예) `…/stock/#/split` → 분할 매매 계산기 (예전 주소 `#/average`도 자동으로 옮겨줘요)
- 계산기 맨 위의 **[국내 주식 | 해외 주식]** 버튼은 모든 계산기가 함께 따라가요. 한 곳에서 해외로 바꾸면
  다른 계산기도 해외(달러, 해외 수수료·양도소득세)로 열려요. 국내 값과 해외 값은 따로 기억해서 바꿔도 지워지지 않아요.
- **해외 주식 원화↔달러** (손실 회복 계산기 빼고 모든 계산기)
  - 해외를 고르면 버튼 아래에 **기준 환율** 한 줄이 생겨요. 직접 넣거나 **오늘 환율**을 누르면
    공개 환율 API(Frankfurter, 유럽중앙은행 기준·하루 한 번 갱신)에서 달러-원 환율을 받아와요. 모든 계산기가 이 환율을 함께 써요.
  - **원화로 넣기:** 달러 칸 왼쪽의 **[$]** 를 누르면 **[₩]** 로 바뀌고, 원화로 넣으면 기준 환율로 나눠 달러로 계산해요.
    칸 아래에 다른 통화로 얼마인지 보여줘요 (≈ 130,000원 / = $100 · 환율 1,300원). 칸마다 고른 통화를 기억해요.
  - **결과:** 큰 숫자 아래에 다른 통화를 한 줄 더 보여주고(≈ 154,294원 · 환율 1,400원),
    결과 카드 오른쪽 위 **[$ | 원]** 으로 세부 금액을 달러/원화로 바꿔 봐요 (적립식은 그래프·표까지). 기본은 $.
  - 매도 시 환율처럼 계산기에 자기 환율이 있으면 원화 환산도 그 환율로 해요. 매도 시 환율 칸의 처음 값은 기준 환율이에요.
  - 배당·적립식 계산기의 환율 칸은 기준 환율로 합쳤어요.
- 상단 바 오른쪽에 **인터넷 연결 상태**(● 온라인 / ● 오프라인)가 늘 보여요. 누르면 설명을 보여주고 다시 확인해요.
  - 몇 초마다 확인하지 않고 브라우저의 `online`/`offline` 알림을 받아요. 데이터 요청이 네트워크 오류로 실패하거나
    다른 탭에서 돌아오면 우리 사이트에 작은 확인 요청을 1번 보내요. 와이파이는 있는데 인터넷이 안 될 때만 15→30→60초 간격으로 다시 확인해요.
  - 오프라인이면 인터넷이 필요한 버튼(해외 계산기의 **오늘 환율**, 시장 지표의 **새로고침·다시 시도**)이 저절로 꺼지고,
    연결이 돌아오면 다시 켜져요. 시장 지표는 못 받은 값을 저절로 다시 불러와요. 계산기는 인터넷 없이도 그대로 돼요.
  - 휴대폰에서 기록 버튼과 같이 있을 때는 온라인을 초록 점으로만 보여줘요.
  - 인터넷이 필요한 버튼에는 `data-needs-net`을 붙이면 app.js가 연결 상태에 맞춰 켜고 꺼요 (`data-busy`면 켜지 않아요).
- 입력값과 계산 기록은 **창(탭)이 열려 있는 동안만** 남아요. 다른 기능으로 이동하거나 새로고침해도 그대로이고,
  탭을 닫고 다시 접속하면 처음 상태로 시작해요. 메뉴 아래 "지금 모두 초기화"로 바로 지울 수도 있어요.
- 같은 메뉴 그룹(예: 계산기)의 기능끼리는 계산 기록을 함께 봐요. 기록 창 위쪽 칩으로 "이 기능만" 볼 수도 있고,
  다른 계산기의 기록을 누르면 그 계산기로 이동해서 값을 불러와요.
- **분할 매매 계산기** (예전 물타기 계산기)
  - **분할 매수:** 나눠서 더 사면 평균 단가가 얼마가 되는지 보여줘요.
  - **분할 매도:** "매도가 + 수량"을 단계로 늘리고 줄여요. 단계별 받는 돈·순이익, 평균 매도가,
    그리고 **남은 주식의 실질 단가**(넣은 돈 − 받은 돈 ÷ 남은 수량)를 보여줘요. 받은 돈이 넣은 돈보다 많으면 "원금 회수 완료".
    해외는 환율을 넣으면 양도소득세(기본 공제 250만 원 뒤 22%)를 원화로 계산해요.
- 계산 결과를 다른 계산기로 바로 넘길 수 있어요. 분할 매수 결과의 "이 평단으로 이어서 계산"에서
  - **목표가 계산 →** 새 평단이 목표가 계산기의 매수가로 들어가요 (목표 수익률·수수료는 원래 값 유지).
  - **손익 계산 →** 새 평단(소수 둘째 자리까지)과 총 보유 수량이 손익 계산기로 들어가고,
    커서가 매도가 칸으로 가요. 매도가만 바꿔 보며 예상 순손익과 매도로 받을 돈을 볼 수 있어요.
- **배당금 계산기**
  - **내 배당:** 주당 배당금(1회)·배당 주기·보유 수량으로 1회·한 달·1년 세후 배당과 배당 수익률(현재가·내 평단 기준)을 보여줘요.
  - **목표 배당:** "한 달(1년)에 세후 얼마 받으려면?" → 필요한 수량(1주 단위 올림)과 투자금, 가진 돈으로는 얼마가 되는지.
  - 세금: 국내 배당소득세 15.4%, 해외는 현지 원천징수(미국 15%). 해외는 기준 환율로 원화도 함께 보여줘요.
  - 1년 세전 배당이 2,000만 원을 넘으면 금융소득종합과세 경고를 보여줘요.
- **적립식 계산기**
  - **얼마가 될까:** 처음 넣는 돈 + 매달 넣는 돈을 주가 상승률·배당률로 굴리면 기간 뒤 얼마가 되는지.
    연도별 막대그래프(원금 + 수익, 막대를 누르면 그 해 금액)와 연도별 표, 배당 재투자 효과, 72 법칙, 물가 반영.
  - **목표 금액:** 기간 뒤 목표를 만들려면 매달 얼마를 넣어야 하는지 (국내 1,000원, 해외 $1 단위 올림).
  - 해외는 다 팔 때 양도소득세(기본 공제 뒤)와 원화 환산을 보여줘요. 배당 계산기의 "적립식으로 보기 →"로 이어져요.
- **손실 회복 계산기** (국내/해외 구분 없이 %만)
  - 지금 손실률을 넣으면 본전까지 필요한 상승률 (−30%면 30%가 아니라 +42.86%, = 손실률 ÷ (1 − 손실률)).
  - 앞으로 오르고 내리는 줄을 **한 줄에 [기간][단위▾] [▲/▼] [%]**로 넣어요 ("3일 ▼5%", "2주 ▲8%", 최대 50줄 = 50년 한도와 맞춤).
    "+ 1줄"·"+ 5줄"은 마지막 줄과 같은 값으로 추가하고, ⧉로 그 줄을 복사해요. 10줄이 넘으면 목록 안에서만 스크롤.
    "그 뒤로 매일·매주·매달·매년 a%"를 넣으면 언제 본전을 회복하는지 계산해요. 오르내림은 곱해서 계산 (+20% 뒤 −20%는 −4%).
  - 기간은 거래일로 이어 붙여요 (1주 = 5, 1달 = 21, 1년 = 252거래일). 한 줄 안에서는 매일 같은 비율로 움직인다고 봐요.
  - 그래프 기본은 **흐름 차트**: 본전 아래는 파랑·위는 빨강 면, 입력한 줄마다 번갈아 옅은 띠(번호), 지금·최저·본전 회복 표시,
    그래프 위를 누르거나 움직이면 십자선이 그날 날짜와 값을 보여줘요.
  - **일봉·주봉·월봉·년봉**: 봉 폭은 읽기 좋게 두고 옆으로 밀어서 보며, 보이는 봉에 맞춰 세로 눈금을 다시 잡아요.
    봉이 3개보다 적거나 1,500개보다 많은 단위는 이유와 함께 막아요. 보기를 바꿔도 보던 날짜가 가운데에 와요.
  - 모든 보기가 같은 날짜축(오늘부터 거래일, 주말·공휴일 몫 제외)과 같은 눈금 규칙(주·달·분기·해 중 글자가 안 겹치는 단계)을 써요.
  - **손실률별 필요한 상승률**: 손실률(1~99.99%)을 넣으면 그 값과 위아래로 1%씩 5줄, 모두 11줄을 보여줘요
    (기본값은 지금 손실률. 예: 33.17 → −28…−32, −33.17, −34…−38%).
- **해외 주식 손익 쪼개 보기 (환차익 분리)**: 해외를 골랐을 때 손익 계산기와 분할 매도 결과에서
  원화 손익을 **주가로 번 돈**((매도가 − 매수가) × 수량 × 산 날 환율)과 **환율로 번 돈**(판 금액 × 환율 변화)으로 나눠요.
  두 몫의 합은 원화 매매 차익과 정확히 같고, 상황에 맞는 한 줄 해석(예: "환율이 내려서 원화로는 65,000원 덜 벌었어요")을 보여줘요.
  매수 시 환율을 넣어야 나뉘어요. 두 계산기가 같은 모듈(core/fx-split.js)을 써서 같은 거래면 숫자가 같아요.
- **목표가 계산기**는 해외에서 목표가를 두 가지로 보여줘요. 양도세 공제(250만 원) 안이면 세금 없는 목표가,
  공제를 다 썼다면 22%를 떼고도 목표 수익률이 되는 가격이에요.
  "환율까지 생각하기"(산 날 환율, 팔 때 예상 환율)를 넣으면 원화로 목표 수익률이 되는 달러 목표가도 보여줘요.
- **하락 대응 계산기**는 주가가 떨어졌을 때의 계획을 세워요.
  - **물타기 계획:** "매수가 + 목표 평단"을 한 세트로 단계를 늘리고 줄여요. 단계마다 몇 주를 사야 하는지,
    본전 가격이 얼마나 내려가는지, 손절선까지 가면 얼마를 잃는지 보여줘요.
  - **손절 후 재매수:** 손절가에 모두 팔고 재매수가에 다시 사면 확정 손실과 새 본전 가격이 얼마인지 보여줘요.
  - 두 탭을 모두 입력하면 **그대로 보유 / 물타기 / 손절 후 재매수**를 본전 가격·추가로 넣는 돈·보유 수량으로 비교해요.
    (어느 쪽이 낫다고 추천하지는 않고 숫자만 나란히 보여줘요)
- **시장 지표** (메뉴의 '정보' 묶음, `#/fx`) — 서버 없이 브라우저에서 바로 받을 수 있는 데이터만 모았어요.
  - **국내 증시:** 코스피, 코스닥, 코스피200, 코스피200 선물 실시간 값과 전일 대비, 장중/장 마감.
    장중에 이 화면을 보고 있으면 1분마다 새로 받아요 (탭을 숨기거나 화면을 떠나면 멈춰요).
  - **해외 선물(참고):** 나스닥100, WTI 원유, 금 — TradingView 위젯을 끼워 넣어 **보여주기만** 해요.
    진짜 선물은 무료 위젯에서 막혀 있어서 선물을 따라 움직이는 CFD 시세예요. 위젯 색은 미국식(상승 초록·하락 빨강)이에요.
  - **환율:** 원/달러, 엔/달러, 원/100엔, 원/위안, 원/유로, 달러 인덱스(근사값, 6개 통화 공식).
    유럽중앙은행 기준가라 하루 한 번 바뀌고, 전 영업일 대비 변화를 보여줘요.
    **[원/달러 … 기준 환율로 쓰기]** 를 누르면 해외 계산기들이 쓰는 기준 환율에 들어가요.
  - **금리:** 한국 기준 금리(코드에 적어 둔 값, `fx/sources.js`의 `KR_BASE_RATE` — 바뀌면 직접 고쳐요),
    미국 기준 금리 목표 범위와 실효 금리(뉴욕 연은), 국채 1개월~30년(미국 재무부), 장단기 금리차(10년 − 2년, 마이너스면 "역전").
    변화는 bp(0.01%p) 단위예요.
  - **금·비트코인:** 금 현물 $/온스와 원/g, 비트코인 업비트(원)·바이낸스($) 실시간 값.
  - 출처를 동시에 받고 도착하는 대로 그려요. 한 곳이 실패해도 그 줄만 "다시 시도"가 나와요.
    1분 안에 다시 들어오면 받아둔 값을 쓰고, **새로고침**을 누르면 모두 다시 받아요. 계산이 아니라서 기록 버튼은 없어요.
  - 넓은 화면은 왼쪽(국내 증시·환율·금/비트코인)·오른쪽(해외 선물·금리) 두 열, 휴대폰은 국내 증시 → 해외 선물 → 환율 → 금리 → 금/비트코인 순서예요.

  | 값 | 출처 (모두 키 없음) | 갱신 |
  |---|---|---|
  | 국내 지수·코스피200 선물 | 네이버 증권 (JSONP, **비공식**, `core/naver.js`) | 실시간 |
  | 해외 선물 | TradingView 위젯 (보기만) | 실시간 |
  | 환율·달러 인덱스 | api.frankfurter.dev (유럽중앙은행) | 영업일 하루 한 번 |
  | 미국 기준 금리·실효 금리 | markets.newyorkfed.org | 영업일 하루 한 번 |
  | 미국 국채 금리 | home.treasury.gov (CSV) | 영업일 하루 한 번 |
  | 한국 기준 금리 | 코드에 적어 둔 값 (한국은행 발표 확인) | 바뀔 때 직접 |
  | 금 현물 | api.gold-api.com | 실시간 |
  | 비트코인 | api.upbit.com, api.binance.com | 실시간 |

  **JSONP:** 브라우저는 다른 사이트의 데이터를 fetch로 읽는 걸 막지만(CORS), `<script>` 태그로 불러온 코드는 실행해요.
  네이버 시세 주소에 `_callback=내함수`를 붙이면 `내함수({...})` 모양으로 답해서 값을 받을 수 있어요.
  공식 API가 아니라서 네이버가 바꾸면 그 카드만 "불러오지 못했어요"가 돼요. 고칠 곳은 `core/naver.js` 하나예요.

  한국 국채 금리, 투자자별 매매 동향은 서버 없이 받을 방법이 없어서 넣지 않았어요.

- **종목 정보** (메뉴의 '정보' 묶음, `#/stock`) — 국내 종목(코스피·코스닥·ETF)을 검색해서 지금 가격과 가치를 봐요.
  - **검색:** 이름 일부나 코드로 바로 찾아요 ("삼성", "005930", 띄어쓰기·대소문자 무시). 같은 순위면 시가총액이 큰 종목부터.
    ↑↓와 Enter로도 고르고, 빈 칸을 누르면 최근 본 종목 5개가 나와요.
  - **가격:** 현재가와 전일 대비, 시가·고가·저가, 상한가·하한가, 거래량·거래대금, 시가총액, 52주 최고·최저 막대(지금 위치).
    정규장 밖에서도 대체거래소(NXT) 프리마켓·애프터마켓 거래 중이면 그렇게 표시하고, 거래 중에 이 화면을 보고 있으면 30초마다 새로 받아요.
  - **가치·배당:** PER(주가 ÷ EPS), 예상 PER(증권사 추정 EPS), PBR(주가 ÷ BPS), EPS·BPS, 1년 주당 배당금·배당 수익률 (최근 결산 기준).
    ETF는 NAV(순자산가치)와 괴리율을 보여줘요.
  - **차트:** 네이버 증권 차트 그림 [오늘·일봉·주봉·월봉·3개월·1년·3년]. 그림이라 보여주기만 해요.
    '오늘'은 장 시작부터 지금까지의 분 단위 선이에요. 5·10·60분봉은 네이버에 그림이 없고, 분봉 데이터는 브라우저에서 막혀 있어서(CORS) 넣지 못했어요.
  - **계산기로 이어서:** 현재가를 손익(매도가)·목표가(매수가)·분할 매매(1차 추가 매수가)·하락 대응(현재가)으로,
    배당 계산기에는 주가와 주당 배당금(지금 고른 배당 주기로 나눈 1회 금액)을 넘겨요. 국내 계산기로 열리고, 평단·수량 같은 내 값은 그대로 둬요.
  - **종목 목록**은 `data/stocks.json` 파일이에요(한국거래소 상장 목록 + 네이버 ETF 목록, 시가총액 순).
    새로 상장된 종목을 넣으려면 `py tools/update-stocks.py`를 실행한 뒤 커밋·배포하면 돼요.

## 새 기능 추가하는 법

1. `js/features/<id>/` 폴더를 만들고 `split/`을 본떠 `index.js`(화면+연결)와 `calculator.js`(계산)를 만들어요.
2. `js/features.js`에서 import하고 `FEATURES` 목록에 넣어요. 끝 — 메뉴와 홈 카드에 저절로 나타나요.
3. 국내/해외에 따라 계산이 달라지면 기능에 `markets: true`를 넣고, `ctx.market`과 `core/market.js`의
   `moneyInput()`(입력칸), `price()`·`money()`(금액 글자)를 써요.
4. 해외 원화↔달러도 쓰려면 `fx: true`를 넣고, 결과 그리기에 `viewMarket(market)`을 넘기고,
   결과 카드 맨 위에 `fxToggle()`, 큰 숫자 아래에 `krwLine()`(달러 결과) 또는 `usdLine()`(원화 결과)을 넣어요.

## 기능끼리 값 넘기기

보내는 기능은 받는 기능의 저장 모양을 몰라도 돼요. 받는 기능이 `receive()`로 "무엇을 받을지"를 직접 정해요.

```
보내는 쪽 (split/index.js)          ctx.sendTo('target', { buyPrice: 47333 })
        │
        ▼
app.js sendTo()                     1. target.receive(지금 입력값, 받은 값, 시장) → 새 입력값 저장
                                       (국내/해외는 모든 기능이 함께 쓰니까 같은 시장으로 넘어가요)
                                    2. #/target 으로 이동
        │
        ▼
받는 쪽 (target/index.js)            receive(): 매수가만 바꾼 입력값을 돌려줌
                                    mount(): ctx.received가 있으면 매수가 칸 강조 + 알림 (core/received.js)
```

다른 기능도 값을 받게 하려면 그 기능의 `index.js`에 `receive(inputs, payload, market)`만 추가하면 돼요.
`app.js`는 고칠 필요가 없어요. 손익 계산기(`profit/index.js`)도 이렇게 `receive()`만 더해서 연결했어요.

지금 연결된 길:

| 보내는 기능 | 받는 기능 | 넘기는 값 |
|---|---|---|
| 손익 (손실일 때) | 손실 회복 | 손실률 (수수료·세금 포함) |
| 손익 (손실일 때) | 하락 대응 | 매수가 → 평단, 수량 → 보유 수량, 매도가 → 현재가 |
| 손익 (이익일 때) | 목표가 | 매수가 |
| 손익 (이익일 때) | 분할 매매 (분할 매도) | 매수가 → 평단, 수량 → 보유 수량, 1차 매도 = 매도가 × 수량 (해외는 환율도) |
| 분할 매매 (분할 매수) | 목표가 | 새 평단 (국내 원 단위, 해외 센트까지) |
| 분할 매매 (분할 매수) | 손익 | 새 평단 (소수 둘째 자리) + 총 보유 수량 |
| 분할 매매 (분할 매수) | 배당 (내 배당) | 새 평단 → 내 평단, 총 보유 수량 → 보유 수량 |
| 배당 (내 배당) | 적립식 (얼마가 될까) | 지금 평가 금액 → 처음 넣는 돈, 배당 수익률·배당세, 배당 다시 투자 |
| 하락 대응 (물타기 계획) | 분할 매매 (분할 매수) | 평단·보유 수량 + 단계별 추가 매수 (기존 추가 매수 줄은 이 단계들로 바뀜) |
| 하락 대응 (물타기 계획) | 손익 | 최종 평단 (소수 둘째 자리) + 총 보유 수량 |
| 하락 대응 (손절 후 재매수) | 손익 | 재매수가 + 재매수 수량 |
| 종목 정보 | 손익 (국내) | 현재가 → 매도가 (커서는 매수가 칸) |
| 종목 정보 | 목표가 (국내) | 현재가 → 매수가 |
| 종목 정보 | 분할 매매 (분할 매수, 국내) | 현재가 → 1차 추가 매수가 (보유 주식·다른 줄은 그대로) |
| 종목 정보 | 하락 대응 (국내) | 현재가 |
| 종목 정보 | 배당 (내 배당, 국내) | 주가 + 1년 주당 배당금 ÷ 지금 배당 주기 |

## 로컬에서 실행하기

JavaScript 모듈(`<script type="module">`)은 보안 규칙 때문에
`index.html`을 **더블클릭해서 열면 동작하지 않아요** (`file://` 주소에서는 모듈을 불러올 수 없음).
아래 방법 중 하나로 간단한 로컬 서버를 띄워서 열어야 해요.

**방법 1. Python** (이 폴더에서 실행)

```bash
py serve.py
```

브라우저에서 http://localhost:8000 접속 (끝내려면 터미널에서 Ctrl+C)

> `py -m http.server`를 그대로 쓰면 Windows에서는 `.js` 파일이 `text/plain` 형식으로 전달돼서
> 모듈이 실행되지 않을 수 있어요. `serve.py`는 이 문제를 바로잡은 버전이에요.

**방법 2. VS Code 확장 "Live Server"**

`index.html`을 연 상태에서 오른쪽 아래 **Go Live** 클릭 → 저장할 때마다 자동 새로고침
